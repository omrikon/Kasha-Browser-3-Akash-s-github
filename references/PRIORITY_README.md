# PRIORITY — READ THIS FIRST

## For agents and humans

**Reference only. Inspiration only. Do not copy.**

Anything under `references/` is for study and design inspiration — mechanics ideas, structure notes, visual references, third-party repos you may clone to learn from.

- **Do not** copy copyrighted code, assets, writing, music, sprites, levels, or other protected material into this project.
- **Do not** paste large chunks from reference repos or screenshots into shipping game files.
- **Do** take notes on *ideas* (feel, pacing, systems) and implement your own original versions.

If you are unsure whether something is too close to a reference: **leave it out**.

## Folder layout

| Folder | Purpose |
|--------|---------|
| `notes/` | Written notes, summaries, design thoughts |
| `repos/` | Cloned GitHub (or other) reference repos — **never committed** |
| `screenshots/` | Playwright MCP / browser screenshots |
| `videos/` | Reference clips / recordings |
| `devlogs/` | Public Devlogs (offline archives). See `devlogs/RAIN_WORLD_DEVLOG.md` |
| `assets/` | Loose reference images / mood material (inspiration only) |

## Git

`references/repos/` is gitignored. Cloned reference repositories must not be pushed to this project's remote.

`references/devlogs/rain-world-devlog-archive/` is also gitignored (large offline media). The index file `references/devlogs/RAIN_WORLD_DEVLOG.md` is tracked.
