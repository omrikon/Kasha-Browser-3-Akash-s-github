`references/devlogs/rain-world-devlog-archive/`

## Re-download

If the local folder is missing:

1. Download `Full.devlog.html` and `style.css` from the latest GitHub release.
2. Clone the `Images` branch of `CandleSign/Rain-World-Devlog` and place the `Images` folder next to the HTML.
3. Open `Full.devlog.html` in a browser.
